# Quick Pest Control Website

A responsive business website created for Quick Pest Control.  
The site provides information about pest control services, company details, and customer contact options through a clean and modern interface.

---

## Features

- Responsive homepage layout
- Service information sections
- About page
- Contact page
- Mobile-friendly navigation
- Custom styling with CSS
- Image-based branding and visual sections

---

## Technologies Used

- HTML5
- CSS3
- JavaScript
